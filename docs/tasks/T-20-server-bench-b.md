# T-20 (server) 홀드 방식 B를 경우별로 한 번 측정

## 배경
홀드 방식 비교를 경우 3가지로 다시 잰다. 측정 도구는 lead가 저장소에 남겼다: `scripts/bench_hold.py`(사용법은 파일 맨 위).
사람 결정: 도구는 현재 서버(A)를 재기 위한 것이고, B는 server가 저장소 밖 복사본에서 다시 만들어 같은 도구로 한 번만 잰 뒤 지운다.
A 결과(lead, 10라운드)는 이미 있다.

## 할 일
1. 저장소 밖(자기 임시 폴더)에 저장소를 복사하고, 그 복사본의 `backend/main.py` 홀드만 T-17 때의 B(조건부 UPDATE … RETURNING 한 번)로 바꾼다. 저장소 안 파일은 바꾸지 않는다.
2. 저장소 루트에서 이렇게 잰다(DB는 tkt_server만, tkt_test는 쓰지 않는다):
   `uv run python scripts/bench_hold.py --runs 10 --app-dir <복사본 경로>`
   다른 측정이나 동시성 테스트와 같은 시각에 돌리지 않는다.
3. 출력 표를 그대로 보고하고, 복사본을 지운다. `git status`로 저장소에 흔적이 없는지 확인한다.

## 보고
출력(앞 두 줄과 표), 복사본에서 B로 바꾼 내용 요약(T-17 때와 같은지), 복사본 삭제 확인. 끝에 `정한 것: ...`, `원칙 충돌: ...`. 보고하고 멈춘다. 커밋하지 않는다.
