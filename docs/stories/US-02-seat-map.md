# US-02 좌석맵 보기

**사용자로서** 공연 하나의 좌석과 각 좌석의 상태를 보고 싶다. **그래야** 잡을 수 있는 좌석을 고를 수 있다.

공통 예시 데이터와 오류 형식은 [PRD](../PRD.md) 5·9절을 따른다. 공연과 좌석은 시드 데이터로 준비한다. 엔드포인트와 필드 이름은 API 계약에서 정한다. 테스트 시각은 주입한다. 좌석맵 조회에는 `X-User-Id`가 필요 없다. 만료된 HELD는 `AVAILABLE`로 보인다.

## 인수 조건

### AC-02-1 모든 좌석이 AVAILABLE(헤더 없이)
- **Given** 공연 `P1`에 좌석 `A1`, `A2`, `A3`이 있고 모두 AVAILABLE이다
- **When** `X-User-Id` 헤더 없이 `P1`의 좌석맵을 요청한다
- **Then** 응답은 2xx다
- **And** 좌석이 정확히 3개(`A1`, `A2`, `A3`)이고 각 상태는 `AVAILABLE`이다

### AC-02-2 상태가 섞여 있을 때
- **Given** 시각 `T0`에 `u2`가 `P1`의 `A1`을 홀드했다
- **And** `u3`가 `P1`의 `A2`를 홀드하고 확정해서 `A2`는 SOLD다
- **When** 시각 `T0 + 1분`에 `X-User-Id` 헤더 없이 `P1`의 좌석맵을 요청한다
- **Then** 응답은 2xx다
- **And** `A1`은 `HELD`, `A2`는 `SOLD`, `A3`은 `AVAILABLE`이다

### AC-02-3 다른 공연의 좌석은 섞이지 않는다
- **Given** 공연 `P1`(좌석 `A1`, `A2`, `A3`)과 `P2`(좌석 `B1`)가 있다
- **When** `X-User-Id` 헤더 없이 `P2`의 좌석맵을 요청한다
- **Then** 좌석은 정확히 1개(`B1`)다

### AC-02-4 없는 공연 `[열린 질문 Q9]`
- **Given** 공연 `P9`는 없다
- **When** `X-User-Id` 헤더 없이 `P9`의 좌석맵을 요청한다
- **Then** 응답은 404이고 본문은 `{"code": "NOT_FOUND", "message": <문자열>}`이다

### AC-02-5 헤더가 있어도 결과는 같다
- **Given** 공연 `P1`의 좌석 `A1`, `A2`, `A3`이 모두 AVAILABLE이다
- **When** `X-User-Id: u1`로 `P1`의 좌석맵을 요청한다
- **Then** 응답과 좌석 목록은 AC-02-1과 같다(2xx, 3개 모두 `AVAILABLE`)

### AC-02-6 만료된 홀드는 AVAILABLE로 보인다
- **Given** 시각 `T0`에 `u2`가 `A1`을 홀드했다
- **When** 시각 `T0 + 4분 59초`에 `P1`의 좌석맵을 요청한다
- **Then** `A1`은 `HELD`다
- **When** 시각 `T0 + 5분`(경계값)에 `P1`의 좌석맵을 요청한다
- **Then** `A1`은 `AVAILABLE`이다

### 열린 질문에 묶인 경우(테스트 보류)
- 좌석맵에 홀드한 사람·만료 시각을 노출하는지 — `[열린 질문 Q7]`
