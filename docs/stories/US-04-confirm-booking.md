# US-04 모의 결제로 예매 확정

**사용자로서** 내가 잡은 좌석을 모의 결제로 확정하고 싶다. **그래야** 그 좌석이 내 예매가 된다.

공통 예시 데이터와 오류 형식은 [PRD](../PRD.md) 3·5·9절을 따른다. 엔드포인트, 요청 대상(홀드 ID인지 좌석 ID인지), 응답 필드는 API 계약에서 정한다. 테스트 시각은 주입한다. 모의 결제는 실제 결제 연동 없이 확정 요청 하나로 처리한다(실패 흉내는 `[열린 질문 Q11]`). 확정 요청에는 `X-User-Id`가 필요하다(없으면 401). 좌석맵 확인은 헤더 없이 한다.

**규칙:** 예매 확정은 그 좌석을 홀드한 사용자가, 그 홀드가 만료되기 전에만 할 수 있다.

## 인수 조건

### AC-04-1 만료 전 본인 홀드 확정 성공
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** 시각 `T0 + 4분 59초`에 `u1`이 `X-User-Id: u1`로 `A1` 확정을 요청한다
- **Then** 응답은 2xx다
- **And** 좌석맵에서 `A1`은 `SOLD`다

### AC-04-2 만료된 홀드는 확정할 수 없다
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** 시각 `T0 + 5분`(경계값)에 `u1`이 `A1` 확정을 요청한다
- **Then** 응답은 409이고 본문은 `{"code": "HOLD_EXPIRED", "message": <문자열>}`이다
- **And** `A1`은 SOLD가 아니다. 이어서 `u2`가 `A1`을 홀드하면 2xx로 성공한다

### AC-04-3 만료 후 다른 사람이 다시 잡은 좌석
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **And** 시각 `T0 + 6분`에 `u2`가 `A1`을 홀드했다
- **When** 시각 `T0 + 7분`에 `u1`이 처음 홀드로 확정을 요청한다
- **Then** 응답은 409 `HOLD_EXPIRED`다
- **And** 이어서 `T0 + 7분`에 `u2`가 확정하면 2xx이고 `A1`은 `SOLD`다

### AC-04-4 이미 SOLD인 좌석의 확정 요청
- **Given** `u1`이 `A1`을 홀드하고 확정해서 `A1`은 SOLD다
- **When** `u2`가 `A1` 확정을 요청한다
- **Then** 응답은 409이고 본문은 `{"code": "SEAT_ALREADY_SOLD", "message": <문자열>}`이다
- **And** `A1`의 구매자는 여전히 `u1`이다(확인 방법은 API 계약에서 정한다, `[열린 질문 Q13]`)

### AC-04-5 확정 동시 요청: SOLD는 한 번
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** 시각 `T0 + 1분`에 `u1`의 확정 요청 10건이 동시에 들어온다
- **Then** `A1`은 `SOLD`이고, 확정(예매)이 기록된 횟수는 정확히 1번이다
- **And** 나머지 9건의 응답 코드는 `[열린 질문 Q1]`의 답에 따른다(그 전에는 "2xx가 최소 1건, SOLD 기록 1번"까지만 검증)

### AC-04-6 홀드부터 확정까지 경쟁: 좌석 하나는 한 번만 팔린다
- **Given** `A1`이 AVAILABLE이고 시각은 `T0`로 고정이다
- **When** 사용자 `u1` … `u10`이 각자 "`A1` 홀드 → 성공하면 바로 확정"을 동시에 실행한다
- **Then** 확정 2xx는 정확히 1건이다
- **And** 그 1건의 사용자는 홀드 2xx를 받은 사용자와 같다
- **And** 좌석맵에서 `A1`은 `SOLD`다

### AC-04-7 사용자 헤더 없음
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** `T0 + 1분`에 `X-User-Id` 헤더 없이 `A1` 확정을 요청한다
- **Then** 응답은 401이고 본문은 `{"code": "UNAUTHORIZED", "message": <문자열>}`이다
- **And** `A1`은 여전히 `HELD`이고, 이어서 `u1`의 확정은 2xx다

### AC-04-8 다른 사용자의 홀드로는 확정할 수 없다
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** 시각 `T0 + 1분`에 `u2`가 `X-User-Id: u2`로 `u1`의 홀드 확정을 요청한다
- **Then** 응답은 2xx가 아닌 오류이고, 본문은 `{code, message}` 두 칸이다. 정확한 상태 코드와 `code`는 `[열린 질문 Q3]`
- **And** 좌석맵에서 `A1`은 여전히 `HELD`다
- **And** 이어서 `T0 + 1분`에 `u1`의 확정은 2xx이고 `A1`은 `SOLD`다

### AC-04-9 홀드 없이는 확정할 수 없다
- **Given** `A1`이 AVAILABLE이고 아무도 홀드하지 않았다
- **When** `u1`이 `X-User-Id: u1`로 `A1` 확정을 요청한다
- **Then** 응답은 2xx가 아닌 오류이고, 본문은 `{code, message}` 두 칸이다. 정확한 상태 코드와 `code`는 `[열린 질문 Q4]`
- **And** 좌석맵에서 `A1`은 여전히 `AVAILABLE`이다

### 열린 질문에 묶인 경우(테스트 보류)
- AC-04-8, AC-04-9의 정확한 상태 코드와 `code` — `[열린 질문 Q3]`, `[열린 질문 Q4]`. 거절된다는 것과 좌석 상태는 지금 테스트할 수 있다.
- 모의 결제 실패 시 동작 — `[열린 질문 Q11]`
