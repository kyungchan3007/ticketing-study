# US-01 공연 목록 보기

**사용자로서** 예매할 수 있는 공연 목록을 보고 싶다. **그래야** 좌석을 고를 공연을 정할 수 있다.

공통 예시 데이터와 오류 형식은 [PRD](../PRD.md) 5·9절을 따른다. 공연은 시드 데이터로 준비한다(등록 API 없음). 엔드포인트와 필드 이름은 API 계약에서 정한다. 공연 목록 조회에는 `X-User-Id`가 필요 없다.

## 인수 조건

### AC-01-1 공연 목록 조회 성공(헤더 없이)
- **Given** 시드에 공연 `P1`("공연 A")과 `P2`("공연 B")가 있다
- **When** `X-User-Id` 헤더 없이 공연 목록을 요청한다
- **Then** 응답은 2xx(정확한 코드는 API 계약)다
- **And** 목록에 공연이 정확히 2개 있다
- **And** 각 공연에 ID(`P1`, `P2`)와 제목("공연 A", "공연 B")이 있다

### AC-01-2 공연이 없을 때
- **Given** 시드에 공연이 하나도 없다
- **When** `X-User-Id` 헤더 없이 공연 목록을 요청한다
- **Then** 응답은 2xx다
- **And** 목록은 빈 배열이다

### AC-01-3 헤더가 있어도 결과는 같다
- **Given** 시드에 공연 `P1`과 `P2`가 있다
- **When** `X-User-Id: u1`로 공연 목록을 요청한다
- **Then** 응답과 목록은 AC-01-1과 같다(2xx, 공연 `P1`·`P2` 2개)
