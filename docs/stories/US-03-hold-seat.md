# US-03 좌석 홀드

**사용자로서** 좌석 하나를 5분 동안 잡아 두고 싶다. **그래야** 결제하는 동안 다른 사람이 그 좌석을 가져가지 못한다.

공통 예시 데이터와 오류 형식은 [PRD](../PRD.md) 3·5·9절을 따른다. 공연과 좌석은 시드 데이터로 준비한다. 엔드포인트와 필드 이름은 API 계약에서 정한다. 테스트 시각은 주입한다. 홀드 유지 시간은 300초이고, 현재 시각 ≥ `expires_at`이면 만료다. 홀드 요청에는 `X-User-Id`가 필요하다(없으면 401). 좌석맵 확인은 헤더 없이 한다.

## 인수 조건

### AC-03-1 AVAILABLE 좌석 홀드 성공
- **Given** `P1`의 `A1`이 AVAILABLE이다
- **When** 시각 `T0`(2026-12-01T10:00:00Z)에 `u1`이 `X-User-Id: u1`로 `A1` 홀드를 요청한다
- **Then** 응답은 2xx다
- **And** 응답에 만료 시각 `2026-12-01T10:05:00Z`(`T0 + 300초`)가 있다
- **And** 이후 좌석맵에서 `A1`은 `HELD`다

### AC-03-2 만료 전 다른 사용자의 홀드 시도는 409
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** 시각 `T0 + 4분 59초`에 `u2`가 `A1` 홀드를 요청한다
- **Then** 응답은 409이고 본문은 `{"code": "SEAT_ALREADY_HELD", "message": <문자열>}`이다
- **And** `A1`의 홀드는 여전히 `u1`의 것이다(이후 `T0 + 4분 59초`에 `u1`의 확정이 성공한다)

### AC-03-3 만료된 홀드는 다시 잡을 수 있다
- **Given** 시각 `T0`에 `u1`이 `A1`을 홀드했다
- **When** 시각 `T0 + 5분`(10:05:00, 경계값)에 `u2`가 `A1` 홀드를 요청한다
- **Then** 응답은 2xx다
- **And** 새 만료 시각은 `2026-12-01T10:10:00Z`다
- **And** `A1`의 홀드는 `u2`의 것이다

### AC-03-4 SOLD 좌석은 홀드할 수 없다
- **Given** `u1`이 `A1`을 홀드하고 확정해서 `A1`은 SOLD다
- **When** `u2`가 `A1` 홀드를 요청한다
- **Then** 응답은 409이고 본문은 `{"code": "SEAT_ALREADY_SOLD", "message": <문자열>}`이다
- **And** 시각을 `T0 + 1시간`으로 옮겨 다시 요청해도 같은 409 `SEAT_ALREADY_SOLD`다
- **And** 좌석맵에서 `A1`은 계속 `SOLD`다

### AC-03-5 서로 다른 사용자의 동시 홀드: 정확히 1건만 성공
- **Given** `A1`이 AVAILABLE이고 시각은 `T0`로 고정이다
- **When** 사용자 `u1` … `u10` 10명이 `A1` 홀드를 동시에 요청한다
- **Then** 2xx 응답은 정확히 1건이다
- **And** 나머지 9건은 모두 409 `SEAT_ALREADY_HELD`다
- **And** 좌석맵에서 `A1`은 `HELD`이고, 성공한 사용자만 이후 확정에 성공한다

### AC-03-6 사용자 헤더 없음
- **Given** `A1`이 AVAILABLE이다
- **When** `X-User-Id` 헤더 없이 `A1` 홀드를 요청한다
- **Then** 응답은 401이고 본문은 `{"code": "UNAUTHORIZED", "message": <문자열>}`이다
- **And** 좌석맵에서 `A1`은 여전히 `AVAILABLE`이다

### AC-03-7 없는 좌석 `[열린 질문 Q9]`
- **When** `u1`이 `P1`의 `Z9`(없는 좌석) 홀드를 요청한다
- **Then** 응답은 404 `NOT_FOUND`다

### 열린 질문에 묶인 경우(테스트 보류)
- 같은 사용자가 `A1`을 동시에 여러 번 홀드 요청 — `[열린 질문 Q1]`
- `u1`이 이미 잡은 `A1`을 만료 전에 다시 홀드 요청 — `[열린 질문 Q2]`
- `u1`이 `A1`을 잡은 상태에서 `A2`도 홀드 요청 — `[열린 질문 Q5]`
